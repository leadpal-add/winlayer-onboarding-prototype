# Changelog

## v1.1 (update for WinLayer review)
- Free first result after signup: Company Brain Lite with verified, user-provided, inferred and unknown facts labeled separately.
- Up to 3 opportunity previews (title, agency, date, source, why it might fit), or an honest empty state when there are no defensible matches.
- Federal readiness checklist with one clear next action; profile can be corrected and saved.
- Entry field now accepts a website; a website alone is not treated as a verified entity.
- Lookup states: not found, inactive, rate-limited and unavailable, each with a way to continue.
- Locked premium actions (Analyze eligibility, Build capture brief) open an upgrade prompt that explains what unlocks.
- Card requested only at trial activation, with trial length, price placeholder and first-charge date shown.
- Checkout outcomes: success returns to the original action with the profile intact; declined card and delayed confirmation handled.
- No fit percentages, win probabilities or award data anywhere; all sample data labeled illustrative.

## v1.0
- One entry field for company name or UEI, ambiguous-name match list, entity confirmation, and free signup with no card.
