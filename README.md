# WinLayer Onboarding Prototype

Interactive prototype of WinLayer's signup-to-first-result flow, built by Able Marketing LLC (Development Division) for WinLayer, following the v7 Free Workspace Activation and Upgrade Spec (Nov 5, 2026).

- Static site: `index.html`, `style.css`, `app.js`. No build step.
- Shared preview link: https://winlayer-onboarding-preview.netlify.app (Netlify, deploys from the `main` branch).
- Prototype only: all company records, matches and opportunities are illustrative samples. Nothing is looked up, saved or charged.
